# 青青草原

一只奶牛和一只奶蛙在卡通草原上跳舞的互动小页面。

**在线打开：** https://bigcow666.github.io/webpage/

## 画面

- 3D 风卡通山谷草原全屏铺满，比例锁定，不缩放不走样
- 奶牛和奶蛙都是抠像后的透明动画，无缝循环（正放+倒放，看不出接头）
- 风效：云朵漂移、叶子飘过、底部一排小草摇摆

## 声音和互动

- 打开页面点一下开始播放声音（浏览器规定，必须先点一下）
- 默认：奶牛的声音满音量，奶蛙的声音小声垫底
- 点一下奶蛙（或把鼠标放上去）：奶蛙声音变大、奶牛变小，约 4 秒后自动恢复

## 兼容做法

为了让各种浏览器（包括华为、小米等手机自带浏览器）都能正常显示透明人物，
人物视频用的是“打包 MP4”：画面上半是彩色、下半是黑白透明说明书，
页面用 WebGL 实时合成。合成不可用时会自动退回动态 WebP 图，再不行退回透明 WebM 视频。

## 文件说明

- `index.html` — 页面本体
- `assets/bg.webp` — 草原背景
- `assets/cow_packed.mp4` / `assets/frog_packed.mp4` — 人物合成版视频
- `assets/cow_anim.webp` / `assets/frog_anim.webp` — 人物动图（兜底）
- `assets/cow.webm` / `assets/frog.webm` — 人物透明视频（兜底）
- `assets/cow.mp3` / `assets/frog.mp3` — 两个角色的声音
